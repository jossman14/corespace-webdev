PERSIAPAN PESERTA
1. Laptop + browser Chrome/Edge
2. VS Code (code.visualstudio.com) + ekstensi "Live Server"
3. (Opsional) akun GitHub untuk deploy ke GitHub Pages

ALUR PRAKTIKUM (60 menit)
00-starter   : mulai di sini, ikuti TODO di index.html
01-html      : checkpoint 1 – struktur HTML semantik (15')
02-styling   : checkpoint 2 – warna, font, spacing, kartu (15')
03-flexbox   : checkpoint 3 – layout navbar, hero, grid menu (15')
04-final     : checkpoint 4 – responsif untuk HP (10')
Bonus deploy : seret folder 04-final ke app.netlify.com/drop  (5')

Tertinggal? Salin isi folder checkpoint sebelumnya lalu lanjutkan.
